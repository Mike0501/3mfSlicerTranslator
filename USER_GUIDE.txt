3mfSlicerTranslator User Guide

-Getting started

On Windows, open bin/Release/latest/3MFTranslator.exe after building the app.
To build it, install the .NET 10 SDK and run this command from the repository root.

    dotnet build -c Release -o bin/Release/latest

Use the selector in the upper-right corner to switch between English and Italian.
The sun and moon switch changes the theme. The question mark opens the in-app
quick guide. The app saves your language and theme preferences.

-Converting a project

1. Click Browse and choose the source 3MF. Under Source settings to import,
   use its active settings or select an embedded process preset. The app uses
   the active settings for fields missing from the selected preset.
2. In the destination slicer, choose your printer, nozzle, and presets. Save a
   project with a simple object. In the translator, click Reference 3MF and
   open that project, or click Profile to choose a saved destination profile.
3. Click Translate and save and choose a new file name. If the print settings
   differ, choose Use source settings, Keep destination settings, or Review
   manually to select values individually. The app keeps destination values
   where no compatible source value is available. Cancel stops the conversion.
   If the destination has fewer filament slots, the desktop app can ask you
   to confirm or adjust the suggested mapping for the used filaments. When
   multiple filaments share a destination slot, they use the color of the
   lowest-numbered source slot assigned to it.
   If a source filament color is invalid, the app lists the affected slots and
   asks whether to replace those colors with black (#000000). Confirm to
   continue, or cancel without saving a project. Valid colors are preserved;
   replacements are listed in Result details. This applies to every supported
   source slicer, including PrusaSlicer and SuperSlicer imports.
   If a geometry model exceeds the default 128 MiB read limit, the app lists
   the large parts and lets you choose a higher limit for that conversion,
   up to 512 MiB per model, or cancel. The minimum offered includes every
   listed model. Loading large models can require several times their size
   in memory. The chosen limit is included in Result details. It concerns
   uncompressed model data; it does not change the physical print dimensions.
4. Open Result details below the report. Red indicates errors, yellow indicates
   warnings, and green indicates success without warnings. Open the translated
   3MF as a project in the destination slicer, slice it, and check the preview.
   Check that the model fits if the build plate size has changed.

Saving printer profiles

Click Create profile, then New profile and choose the Destination slicer.
To build a profile from compatible installed presets, choose a brand, model, nozzle
preset, compatible build plate, and the number of filament slots. The app uses
the slicer's process and filament presets to export a complete reference 3MF.
Select the saved profile under Profile when converting. The saved reference
continues to work if the original slicer is removed.

To create a custom profile from the Orca catalog, connect an installed or
portable copy of OrcaSlicer. The app checks common installation paths and
previously linked locations, then loads presets when you choose a slicer.
If the Orca catalog is unavailable, click
Connect OrcaSlicer and choose the folder containing orca-slicer.exe. The app
remembers a location after loading compatible presets from it.

The app includes an offline printer model list for Bambu Lab, Anycubic, and
Creality, based on the OrcaSlicer catalog. OrcaSlicer does not need to be
installed to browse these model names. Compatible presets are still read from
the selected slicer when available. If a model has no compatible preset on
this computer, use the 3MF reference workflow below and save a project in the
intended destination slicer.

Click Create profile, then From a 3MF reference. Choose or type the printer brand,
model, nozzle diameter, and build plate to filter the available references.
Leave any field blank to accept all values for that field. If no reference
matches, use Add from 3MF to load a project saved with the required printer and
nozzle in your slicer. If the reference supports multiple plate types, the app
can use a compatible plate with temperatures for the reference's filaments.

Choose a reference and a profile name, then click Save. The library keeps a copy
under %LOCALAPPDATA%\3MFTranslator\references. Select it under Profile when
converting. You can create and use these profiles without the slicer that
generated the 3MF.

Each reference serves as a base preset. Select it and click Customize to save a
variant with a different layer height, wall count, sparse infill density, or
support setting. Variants share the same reference and can be edited later.
To remove a saved profile, select it in the library, click Delete profile,
and confirm. If it was the selected conversion destination, choose another
profile before converting. Other presets sharing its reference remain usable.
During conversion, choose Keep destination settings to apply the selected
variant, or use Review manually to choose individual settings.
Organic support styles are translated to the destination slicer's spelling:
organic for Anycubic Slicer Next, OrcaSlicer and Creality Print;
tree_organic for Bambu Studio.

References added with an earlier version still use their original saved paths.
Use Convert to 3MF to migrate an older local preset, or migrate it on first use.
Migration requires the original slicer and its presets.

Compatibility

Bambu Studio, OrcaSlicer, Anycubic Slicer Next, and Creality Print can be used
as both sources and destinations. For Creality Print, save a reference project
in Creality Print with the intended printer, nozzle, build plate, and enough
filament slots. Use that reference in the desktop app or as reference.3mf on
the command line. The converted project uses the machine settings from the
reference and keeps its values when an imported setting is incompatible.
If the build volume differs, check object placement and height before slicing.

The destination requires one physical FFF nozzle. The app can adapt a
multi-nozzle source when all source nozzles match the destination diameter.

The app also imports compatible PrusaSlicer 2.x and SuperSlicer projects with embedded
geometry and settings, one build plate, and one filament. These imports include
negative volumes, modifiers, instances, and compatible process settings. The
report flags excluded variable layer heights, per-layer events, and height
ranges. This version excludes Cura, the PrusaSlicer 3 project format, and
virtual filaments.

In the shared Bambu/Orca format, the app preserves meshes, plates, positions,
colors, and filament assignments. When the destination has fewer filament
slots, the app can remove unused slots if it can verify the assignments. The
report shows the mapping. The desktop app can also remap supported painted
colors. Projects with per-layer sequences or layer events need enough slots
to preserve the original indices.

Compatible source settings can include layer height, walls, infill, supports,
print speeds, and accelerations. The printer configuration, machine limits,
temperatures, filament profiles, and purging settings come from the destination
reference. The app removes source G-code and reports excluded custom settings.

-Command-line usage

From the repository root, run the following command with new paths for the
output project and report.

    dotnet bin/Release/latest/3MFTranslator.dll convert source.3mf reference.3mf translated.3mf report.txt

To select an embedded preset, add its archive path after the report path,
for example Metadata/process_settings_1.config.

Exit code 0 means the project was saved, 1 means a conversion or write error,
and 2 means invalid arguments.
